1. 项目概述

1.1 项目背景

太仓港作为国内重要商品车滚装港口，每日处理大量商品车的断电操作。为规范操作流程、提升作业效率，开发本应用，为现场作业人员提供断电位置查询、操作步骤指导、照片参考等一站式服务。

1.3 V1.1 更新内容

本次更新（V1.1）修复以下问题：
  • 修复首次打开时长组账号处于登录状态的问题，确保所有账号默认退出登录
  • 修复同步日志显示硬编码默认数据的问题，首次使用显示"暂无同步记录"
  • 修复同步状态默认显示"已同步"的问题，改为首次显示"未同步"
  • 新增6项首次打开状态验证测试（共34项），覆盖登录表单为空、登录前页面不可见、无同步日志、无飞书配置等

1.4 核心功能

  • 用户系统：组长/组员角色分离，注册审核流程，密码管理
  • 车型管理：73款车型断电指导，缩略图预览，树形/平铺视图
  • 数据同步：飞书云端接口，组长上传/组员拉取
  • 操作指导：断电位置、操作步骤、钥匙处理、照片参考
  • 数据导出：支持Word/PDF/Excel单车型导出

5. 数据同步与飞书接口

5.1 同步架构

同步方向：组长 → 飞书云端 → 组员
同步内容：全部73条车型数据（含断电位置、步骤、钥匙处理、照片路径、备注）
触发方式：手动触发（上传/拉取），可配置定时同步间隔

5.2 飞书配置

配置项字段ID说明
App IDfeishu-appid飞书应用唯一标识
App Secretfeishu-secret飞书应用密钥
同步文件夹 Tokenfeishu-folder飞书云空间文件夹Token
同步间隔（分钟）feishu-interval定时同步间隔，默认30分钟

5.3 同步数据格式

{ "version": "v3.0", "timestamp": "2026-08-20T10:00:00.000Z", "uploadedBy": "组长", "vehicleCount": 73, "vehicles": [ { id: 1, brand: "比亚迪", series: "海豚", config: "低配", display: "比亚迪海豚(低配)", powerType: "纯电", position: "...", steps: [...], keyFrame: [...], keyContainer: [...], remarks: "...", photos: 4, photoPaths: ["vehicle_images/xxx.jpg", ...] } ] }

5.4 同步操作

操作权限说明
上传数据至飞书仅组长将本地73条车型数据打包上传到飞书云端
从飞书获取数据所有用户从飞书云端拉取最新数据并覆盖本地
手动拉取飞书数据所有用户强制从飞书获取，用于组员更新

5.5 同步日志

系统记录所有同步操作日志，存储在 localStorage 的 sync_log 键中，包含操作类型、时间戳和结果状态。

8. 安卓打包与部署

8.1 打包流程

  1. 将 demo.html 复制为 tcg_app/www/index.html
  2. 将 vehicle_images/ 复制到 tcg_app/www/vehicle_images/
  3. 创建 Cordova 项目：cordova create tcg_app com.tcg.poweroff
  4. 添加 Android 平台：cordova platform add android
  5. 配置环境变量：JAVA_HOME, ANDROID_HOME, GRADLE_HOME
  6. 在 gradle.properties 中添加 android.overridePathCheck=true（路径含中文）
  7. 执行 Gradle 构建：gradle cdvBuildDebug
  8. 获取 APK：platforms/android/app/build/outputs/apk/debug/app-debug.apk
  9. 重命名为：太仓港断电指导V1.0.apk

8.2 环境变量配置

JAVA_HOME=C:\jdk17\jdk-17.0.13+11 ANDROID_HOME=C:\Android\Sdk ANDROID_SDK_ROOT=C:\Android\Sdk GRADLE_HOME=C:\gradle\gradle-8.11.1 PATH=%JAVA_HOME%\bin;%ANDROID_HOME%\cmdline-tools\latest\bin;%GRADLE_HOME%\bin;%PATH%

8.3 重新构建命令

cd e:\车辆断电指导应用开发\tcg_app\platforms\android gradle cdvBuildDebug -b build.gradle --no-daemon

8.4 安装说明

  • 将 太仓港断电指导V1.0.apk 传输到 Android 手机
  • 在手机上允许"安装未知来源应用"
  • 点击安装，安装完成后打开应用
  • 首次使用需注册账号：组长手机号 17602554481 注册即生效
  • 组员手机号注册后需等待组长审核

10.2 飞书接口（预留）

当前版本使用 localStorage 模拟飞书云端存储。实际部署时，需对接飞书开放平台API：
1. 获取Token：POST https://open.feishu.cn/open-apis/auth/v3/tenant_access_token/internal
2. 上传文件：POST https://open.feishu.cn/open-apis/drive/v1/files/upload_form
3. 下载文件：GET https://open.feishu.cn/open-apis/drive/v1/files/{file_id}
