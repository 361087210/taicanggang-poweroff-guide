1. 项目概述

太仓港作为国内重要商品车滚装港口，每日处理大量商品车的断电操作。为规范操作流程、提升作业效率，开发本应用，为现场作业人员提供断电位置查询、操作步骤指导、照片参考等一站式服务。

3. 全屏自适应显示

3.1 问题描述

之前版本使用模拟手机外框（phone-frame）和刘海（phone-notch）元素，导致：

  • 界面四周有黑色边框，浪费屏幕空间
  • 刘海元素遮挡顶部内容
  • 不同屏幕比例设备显示不一致

3.2 解决方案

移除模拟器外框和刘海，使用 CSS 视口单位实现全屏自适应：

/* 全屏自适应容器 */ .phone-frame{ width:100vw; height:100vh; height:100dvh; /* 动态视口高度，适配移动端地址栏 */ background:#f5f6fa; position:relative; overflow:hidden; } .phone-screen{ width:100%; height:100%; background:#f5f6fa; overflow:hidden; position:relative; }

3.3 Cordova 配置

在 config.xml 中配置 edge-to-edge 显示：

<preference name="StatusBarOverlaysWebView" value="false" /> <preference name="Fullscreen" value="false" /> <preference name="edge-to-edge" value="true" />

3.4 设备信息动态检测

移除硬编码设备型号，改为运行时动态检测：

const deviceInfo = { model: navigator.userAgent.match(/Android\s+([\d.]+)/)?.[1] || '未知', screen: screen.width + '×' + screen.height, dpr: window.devicePixelRatio || 1 };

4. 导航历史栈与返回逻辑

4.1 问题描述

之前版本的 goBack() 函数直接跳转到固定页面（如"我的"），导致：

  • 从车型详情返回时跳到错误页面
  • 从同步中心返回时跳到错误页面
  • 多层导航后返回逻辑混乱

4.2 解决方案：导航历史栈

引入 navHistory 数组记录导航路径，实现精准返回上一步：

let navHistory = []; function showScreen(id) { // 记录当前页面到历史栈（主Tab页清空历史） if (state.screen && state.screen !== id) { navHistory.push(state.screen); } if (['screen-vehicles', 'screen-data', 'screen-my'].includes(id)) { navHistory = []; // 主Tab页清空历史 } _activateScreen(id); } function goBack() { const target = navHistory.pop() || 'screen-vehicles'; _activateScreen(target); }

4.3 _activateScreen 统一激活函数

将屏幕激活逻辑抽取为独立函数，确保 showScreen 和 goBack 行为一致：

function _activateScreen(id) { document.querySelectorAll('.screen').forEach(s => s.classList.remove('active')); document.getElementById(id).classList.add('active', 'screen-slide'); state.screen = id; // 更新底部导航高亮 if (['screen-vehicles', 'screen-data', 'screen-my'].includes(id)) { state.tab = id.replace('screen-', ''); updateBottomNav(); } }

4.4 导航路径示例

5. 车辆详情分享与编辑删除

5.1 真实分享控件

调用系统 Web Share API，弹出原生分享面板；不支持时自动降级为剪贴板复制：

async function shareVehicleDetail() { const v = VEHICLES.find(x => x.id === state.currentVehicleId); if (!v) return; const shareText = `${v.display} - 断电指导\n品牌：${v.brand}\n配置：${v.config}\n断电位置：${v.position}\n\n断电步骤：\n${v.steps.map((s,i) => (i+1)+'. '+s).join('\n')}`; const shareData = { title: v.display + ' 断电指导', text: shareText }; if (navigator.share) { try { await navigator.share(shareData); } catch(e) { if (e.name !== 'AbortError') showToast('分享取消'); } } else if (navigator.clipboard) { try { await navigator.clipboard.writeText(shareText); showToast('已复制断电信息到剪贴板'); } catch(e) { showToast('分享功能不可用'); } } else { showToast('当前环境不支持分享'); } }

5.2 车辆编辑功能

详情页"编辑"按钮跳转编辑界面，保存后实时刷新详情页数据：

function saveVehicle() { // 收集表单数据 const vehicleData = { id: state.currentVehicleId, display: document.getElementById('edit-display').value, brand: document.getElementById('edit-brand').value, // ... 其他字段 }; // 更新 VEHICLES 数组 if (state.currentVehicleId) { const idx = VEHICLES.findIndex(v => v.id === state.currentVehicleId); if (idx >= 0) VEHICLES[idx] = { ...VEHICLES[idx], ...vehicleData }; else VEHICLES.push(vehicleData); } // 保存到 localStorage localStorage.setItem('vehicles_data', JSON.stringify(VEHICLES)); // 关键：刷新详情页而非返回 openVehicleDetail(state.currentVehicleId); showToast('保存成功'); }

5.3 车辆删除功能

详情页"删除"按钮，确认后从 VEHICLES 数组移除并返回列表：

function deleteVehicle() { if (!confirm('确认删除该车型？此操作不可撤销。')) return; const idx = VEHICLES.findIndex(v => v.id === state.currentVehicleId); if (idx >= 0) { VEHICLES.splice(idx, 1); localStorage.setItem('vehicles_data', JSON.stringify(VEHICLES)); showToast('已删除'); showScreen('screen-vehicles'); renderVehicleList(); } }

6. 悬浮提示修复

6.1 问题描述

Toast 通知存在两个问题：

  • 上下跳动：CSS 使用 transform 动画导致位置抖动
  • 长时间不消失：setTimeout 被重复调用导致计时混乱

6.2 CSS 修复

改用 opacity 过渡，消除位移抖动：

.toast{ position:absolute; bottom:90px; left:50%; transform:translateX(-50%); background:rgba(0,0,0,.82); color:#fff; padding:8px 20px; border-radius:20px; font-size:13px; z-index:400; opacity:0; pointer-events:none; transition:opacity .15s; /* 仅 opacity 过渡 */ white-space:nowrap; max-width:90%; } .toast.show{ opacity:1; }

6.3 JavaScript 修复

清除重复计时器，确保每次调用只有一个定时器：

let toastTimer = null; function showToast(msg) { const toast = document.getElementById('toast'); if (!toast) return; toast.textContent = msg; toast.classList.add('show'); // 清除已有计时器，避免重复 if (toastTimer) clearTimeout(toastTimer); // 1.5秒后自动消失 toastTimer = setTimeout(() => { toast.classList.remove('show'); toastTimer = null; }, 1500); }

7. 安全加固与代码优化

7.1 XSS 防护

所有动态内容插入点实施 HTML 转义，防止跨站脚本攻击：

function esc(str) { if (str == null) return ''; return String(str) .replace(/&/g, '&amp;') .replace(/</g, '&lt;') .replace(/>/g, '&gt;') .replace(/"/g, '&quot;') .replace(/'/g, '&#39;'); }

所有通过 innerHTML 插入的动态数据均经过 esc() 转义处理。

7.2 凭证安全

  • 移除代码中硬编码的飞书 API Token
  • 敏感配置改为运行时从 localStorage 读取
  • 不存储明文密码，使用 SHA-256 哈希比较

7.3 代码优化

  • 导航逻辑统一：_activateScreen 函数避免代码重复
  • Toast 计时器管理：单例计时器避免内存泄漏
  • 事件监听清理：避免重复绑定导致的事件触发多次
  • localStorage 数据校验：读取时增加 JSON 解析异常处理

10. 数据同步与飞书接口

10.1 同步架构

  • 组长上传：将本地 VEHICLES 数组数据上传至飞书多维表格
  • 组员拉取：从飞书多维表格拉取最新数据到本地
  • 同步状态：初始显示"未同步"（灰色），成功后变"已同步"（绿色）

10.2 同步中心

首次进入同步中心显示"暂无同步记录"，不显示任何模拟历史日志。同步操作完成后记录实时写入。

13. 已知限制与后续规划

13.1 已知限制

  • Web Share API 在部分旧版 Android 上不可用，降级为剪贴板复制
  • 飞书同步需要网络连接，离线状态下仅可查看本地数据
  • 车辆图片为本地存储，APK 体积较大（约15MB）

13.2 后续规划

  • 图片云端化，减小 APK 体积
  • 支持车型数据版本管理和回滚
  • 增加操作记录审计日志
  • 支持多语言（中/英）
