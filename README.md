# 太仓港商品车断电操作标准化指导平台 V5.2

> 太仓港商品汽车断电操作标准化指导应用，支持车辆信息管理、操作指导、文档导出与社交分享、数据备份、云同步与应用内更新。

## 版本信息

- **当前版本**: V5.2
- **更新日期**: 2026-08-20
- **适用平台**: Android 7.0+ (API 24+)

## 核心功能

### 1. 车辆管理
- 73+ 辆车辆数据，覆盖10个品牌
- 车辆列表展示（缩略图、品牌筛选、搜索）
- 车辆详情查看（图片、视频、操作步骤）
- 新增/编辑/删除车辆信息

### 2. 文档导出与社交分享 (V4.0 新增, V5.2 增强)
- **Excel导出**: 批量/单辆车辆数据，包含图片路径和视频链接
- **PDF导出**: 格式化车辆信息报告，包含图片信息
- **Word导出**: 结构化车辆文档，包含图片和视频引用
- **社交分享 (V5.2)**: 集成原生socialsharing插件，Word/PDF/Excel文件直接调起系统分享面板，分享到微信/QQ/钉钉等主流应用
- **三级降级策略**: 原生分享插件 -> Web Share API -> 浏览器下载，任意环境可用
- **MIME自动修正**: docx/xlsx/doc/pdf扩展名与MIME类型严格对应，避免微信识别异常

### 3. 媒体管理 (V4.0 新增)
- 编辑车辆时可直接拍照或从相册选择照片
- 支持视频选择（最大100MB）
- 图片自动压缩（最大800px，质量70%）
- 最多9张照片预览与管理

### 4. 数据备份 (V4.0 增强)
- **本地备份**: JSON格式完整数据导出
- **飞书云备份**: 一键上传至飞书云盘
- 飞书配置内置，无需手动配置

### 5. 云同步
- 飞书开放平台API集成
- 数据上传/下载同步
- 默认配置内置（App ID、Secret、文件夹Token）

### 6. 安全与权限
- 基于角色的登录系统（组长/组员）
- XSS防护（所有动态内容转义）
- Cordova权限配置（相机、存储、网络）
- 全屏适配（无边框、刘海屏适配）

## 技术栈

- **前端**: HTML5 + Tailwind CSS + JavaScript (单页应用)
- **移动端**: Apache Cordova (Android)
- **文档生成**: SheetJS (xlsx) + jsPDF + html-docx-js
- **云服务**: 飞书开放平台 API
- **构建工具**: Gradle 8.14.2 + Cordova CLI

## 快速开始

### 浏览器预览
直接用浏览器打开 `demo.html` 即可使用全部功能。

### Android安装
1. 下载 `release/太仓港断电指导V5.1.apk`
2. 在Android设备上安装（需允许未知来源安装）
3. 首次打开显示登录页面，使用账号登录

## 应用内检查更新

应用启动3秒后自动静默检查更新（可在"我的-检查更新"手动触发），多源获取版本信息：
1. GitHub Raw (`raw.githubusercontent.com`)
2. jsDelivr CDN (`cdn.jsdelivr.net`)
3. 飞书云盘兜底（`version.json`）

检测到新版本时弹窗展示更新日志与安装包大小，由用户选择"下载新版本安装包"（跳转GitHub Release）或"稍后再说"（记住跳过版本）。

发布新版本时只需更新仓库根目录 `version.json` 并在 GitHub Releases 上传新APK。
