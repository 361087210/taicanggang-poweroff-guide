# 太仓港商品车断电指导 APP

太仓港商品车断电操作标准化指导平台，为现场作业人员提供断电位置查询、操作步骤指导、照片参考等一站式服务。

## V3.1 更新内容

### 全屏自适应显示
- 去除界面黑边和模拟器刘海
- 实现 100vw/100vh 全屏自适应
- 支持动态视口高度 (100dvh)

### 导航返回逻辑修复
- 实现导航历史栈 (navHistory)
- 多界面返回上一步不再失效
- 主Tab页清空历史，避免历史栈污染

### 车辆详情分享与编辑删除
- 调用系统 Web Share API 原生分享面板
- 不支持时自动降级为剪贴板复制
- 详情页新增编辑/删除按钮，数据实时持久化

### 悬浮提示修复
- 修复 Toast 上下跳动问题（改用 opacity 过渡）
- 修复 Toast 长时间不消失问题（单例计时器）

### 安全加固
- XSS 防护：所有动态内容插入点 HTML 转义
- 凭证安全：移除硬编码 Token
- 代码优化：导航逻辑统一、Toast 计时器管理

## 文件说明

| 文件 | 说明 |
|------|------|
| demo.html | 主应用代码（HTML+CSS+JS 单文件） |
| test_full_v3.py | 自动化测试脚本（Playwright） |
| build_apk_v31.bat | APK 构建脚本 |
| tcg_app/config.xml | Cordova 配置文件 |
| vehicle_images/ | 车辆照片目录（112张） |

## 技术栈

- HTML5 + CSS3 + JavaScript (单文件应用)
- Cordova (Android WebView 混合应用)
- Playwright (自动化测试)
- 飞书 API (云端数据同步)
