# 太仓港商品车断电操作标准化指导平台 V4.0

> 太仓港商品汽车断电操作标准化指导应用，支持车辆信息管理、操作指导、文档导出、数据备份与云同步。

## 版本信息

- **当前版本**: V4.0
- **更新日期**: 2026-08-20
- **适用平台**: Android 7.0+ (API 24+)

## 核心功能

### 1. 车辆管理
- 73+ 辆车辆数据，覆盖10个品牌
- 车辆列表展示（缩略图、品牌筛选、搜索）
- 车辆详情查看（图片、视频、操作步骤）
- 新增/编辑/删除车辆信息

### 2. 文档导出 (V4.0 新增)
- **Excel导出**: 批量/单辆车辆数据，包含图片路径和视频链接
- **PDF导出**: 格式化车辆信息报告，包含图片信息
- **Word导出**: 结构化车辆文档，包含图片和视频引用
- **手机分享**: 导出后自动调用系统分享控件

### 3. 媒体管理 (V4.0 新增)
- 编辑车辆时可直接拍照或从相册选择照片
- 支持视频选择（最大100MB）
- 图片自动压缩（最大800px，质量70%）
- 最多9张照片预览与管理

### 4. 数据备份 (V4.0 增强)
- **本地备份**: JSON格式完整数据导出
- **飞书云备份**: 一键上传至飞书云盘
- 飞书配置内置，无需手动配置

### 5. 云同步
- 飞书开放平台API集成
- 数据上传/下载同步
- 默认配置内置（App ID、Secret、文件夹Token）

### 6. 安全与权限
- 基于角色的登录系统（组长/组员）
- XSS防护（所有动态内容转义）
- Cordova权限配置（相机、存储、网络）
- 全屏适配（无边框、刘海屏适配）

## 技术栈

- **前端**: HTML5 + Tailwind CSS + JavaScript (单页应用)
- **移动端**: Apache Cordova (Android)
- **文档生成**: SheetJS (xlsx) + jsPDF + html-docx-js
- **云服务**: 飞书开放平台 API
- **构建工具**: Gradle 8.14.2 + Cordova CLI

## 快速开始

### 浏览器预览
直接用浏览器打开 `demo.html` 即可使用全部功能。

### Android安装
1. 下载 `release/太仓港断电指导V4.0.apk`
2. 在Android设备上安装（需允许未知来源安装）
3. 首次打开显示登录页面，使用账号登录

### 默认账号
- **组长**: 17602554481 (完整权限)
- **组员**: 需组长审批后登录
