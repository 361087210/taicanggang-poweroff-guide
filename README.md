## CI/CD（V5.3.1 新增）

- **CI 校验流水线**：每次 push 自动执行资产校验 + 凭证泄露扫描 + 映射表漂移检测（`.github/workflows/ci.yml`）
- **Release 构建流水线**：推送 `v*` 标签即自动构建签名 APK 并发布 GitHub Release，独立构建号 buildNumber 区分产物（`.github/workflows/android-release.yml`）
- 签名密钥已移出 git 跟踪，密码走 GitHub Secrets / 环境变量，详见 [CI/CD使用说明](docs/CICD使用说明.md)
- 本地提交前自查：`node scripts/validate_web_assets.js`

## 核心功能

### 1. 车辆管理
- 73+ 辆车辆数据，覆盖10个品牌
- 车辆列表展示（缩略图、品牌筛选、搜索）
- 车辆详情查看（图片、视频、操作步骤）
- 新增/编辑/删除车辆信息

### 2. 文档导出与社交分享 (V5.8 对齐安装包 V1.8 方案)
- **Excel/PDF/Word导出**: 批量/单辆车辆数据，包含图片和视频引用
- **单车Excel四工作表 (V5.8)**: 车辆信息/断电步骤/媒体资源/备注，缺失字段"未填写"兜底
- **批量Excel汇总+详情 (V5.8)**: 汇总表(导出时间/记录总数+11列标准表头) + 前10辆详情子表
- **CSV规范 (V5.8)**: 11列标准表头 + UTF-8 BOM + CRLF行尾，Windows Excel双击直开
- **JSON元信息结构 (V5.8)**: `{appVersion,backupAt,vehicles,users}`，非裸数组
- **文件命名对齐 (V5.8)**: 单车`{显示名}_断电指南.*`、批量`vehicle_poweroff_export_*`、批量Word`车辆断电指南_批量_*`、备份`vehicle_poweroff_backup_*`
- **分享标题策略 (V5.8)**: 面板标题缺省回退文件名(对齐安装包)，仅批量JSON传"车辆断电数据导出"
- **分享备份 (V5.8新增)**: 数据中心一键全量备份JSON经系统分享面板发微信/钉钉
- **文件分享三级策略 (V5.3)**: 写缓存文件走`file://`路径（微信/QQ/钉钉对base64兼容差）→ base64回退 → Web Share API → 浏览器下载
- **MIME自动修正**: docx/xlsx/doc/pdf扩展名与MIME类型严格对应
- **导出Loading互斥 (V5.8)**: 全部导出按钮导出中禁用防重复提交，成功后自动清空选择集

### 3. 媒体管理 (V5.3 修复)
- 照片拍照/相册选择，自动压缩（最大800px，质量70%），最多9张
- **旧数据自动迁移 (V5.3)**: `images/`→`vehicle_images/`路径启动自动修复，49条死链引用清洗
- **视频四源回退链 (V5.3)**: 本地APK → 飞书云端（APP数据备份/vehicle_videos） → GitHub CDN → 诚实提示"待补充"
- **视频上传 (V5.3新增)**: 组长可在占位页一键上传真实教学视频（≤20MB）到飞书云端，全组设备自动命中云端源

### 4. 数据备份与云同步 (V5.3 架构升级)
- **数据分仓 (V5.3核心)**: 项目产物（文档/APK/代码）与用户数据（账号/审批/备份）物理分离——用户数据统一存入飞书"APP数据备份"子文件夹，与产物文件夹互不污染
- **原生HTTP通道 (V5.3核心)**: 集成cordova-plugin-advanced-http，APP环境走原生网络栈绕过WebView CORS限制，修复真机所有飞书请求静默失败的根因
- 本地备份: JSON格式完整数据导出
- 飞书云备份: 一键上传/下载，Token/上传/下载均3次自动重试

### 5. 账号与审批 (V5.3 闭环修复)
- 基于角色的登录系统（组长/组员）
- **跨设备注册审批全链路 (V5.3)**: 组员申请上传飞书 → 组长60秒轮询+Toast提醒 → 审批结果上传飞书 → 组员端拉取审批状态，双机不同网络亦可闭环

### 6. 导航与交互 (V5.3 修复)
- **Android硬件返回键统一路由 (V5.3)**: 关查看器→关播放器→关弹层→登录保护→主Tab双击退出→子页面返回上一步；浏览器预览popstate同步支持
- 全屏适配（无边框、刘海屏适配）

### 7. 应用内更新
- 启动3秒后自动静默检查更新（可手动触发），多源探测（GitHub Raw → jsDelivr CDN → 飞书云盘）
- **V5.3**: 多源版本探测统一走httpFetch原生通道+8秒超时，弱网不再无限挂起

## 技术栈

- **前端**: HTML5 + Tailwind CSS (本地化) + JavaScript (单页应用)
- **移动端**: Apache Cordova (android@13)
- **原生插件**: advanced-http（网络）、x-socialsharing（分享）、camera/file/media-capture（媒体）
- **文档生成**: SheetJS + jsPDF + html-docx-js（全部本地化，零CDN外链）
- **云服务**: 飞书开放平台 API
- **构建工具**: Gradle 8.14.2 + Cordova CLI + JDK 17

## 安全说明 (V5.7)

> ⚠️ **重要**: 飞书 App Secret 以 `_fsDec` 混淆形式内置（开箱即用、非明文合规），仍可在「设置 → 飞书配置」覆盖。V5.8 计划升级为服务端代理（Secret 仅存云端环境变量）。

- **凭证存储**: App Secret 保存于 `localStorage`，仅本机可见，不会随 APK 分发
- **代码库零明文**: 源码、文档、测试脚本中均不含明文凭证
- **测试脚本**: 通过环境变量 `FEISHU_APP_SECRET` 传递，不会写入代码
- **安全建议**:
  - 不要将 App Secret 提交到版本控制
  - 定期轮换凭证，尤其是发现泄露风险时
  - 生产环境建议使用服务端代理而非客户端直连飞书 API
