## 三、问题反馈系统详细说明

### 3.1 反馈入口
「我的」→「问题反馈」— 所有登录用户(组长/组员)均可使用

### 3.2 反馈流程
```
用户提交(选择板块+描述+截图+联系方式)
    ↓
本地存储(localStorage,离线可用)
    ↓
飞书可用 → 上传截图到云盘 → 写入多维表格
    ↓
飞书工作流触发 → AI智能体分析
    ↓
生成技术文档 → 通知组长 → 开发者跟进解决
    ↓
状态更新 → 用户端同步展示处理进度
```

### 3.3 8大板块分类
1. 车辆查询模块 — 车型搜索、筛选、详情页问题
2. 断电操作模块 — 操作步骤、视频、文档导出问题
3. 数据同步模块 — 同步失败、数据不一致、延迟问题
4. 账号登录注册 — 登录失败、注册无响应、密码问题
5. 组员管理模块 — 组员增删、审批、角色管理问题
6. 缓存与导出 — 视频缓存、文档导出、清理问题
7. 系统设置 — 户外模式、版本更新、退出登录问题
8. 其他问题 — 不属于以上分类的问题

### 3.4 数据安全
- 反馈数据仅开发者可见,不对外公开
- 联系方式选填,方便针对性回复
- 截图自动压缩到1280px/80%质量,保护隐私同时节省流量

## 六、飞书智能体分析配置说明(需手动开启)

当前版本已完成**数据写入**侧的开发,AI分析侧需在飞书端配置工作流/智能体:

### 6.1 配置步骤
1. 打开飞书多维表格「太仓港断电指导-问题反馈库」
2. 进入「高级功能」→「自动化流程」→「新建流程」
3. 触发条件: 新增记录时
4. 执行动作:
   - 调用智能体分析问题描述 + 截图
   - 智能体输出: 问题原因分析 + 解决方案建议
   - 将分析结果写入「AI分析摘要」字段
   - 生成技术文档并写入「技术文档链接」字段
   - 发送飞书消息通知组长
5. 更新记录状态为「分析中」→「已解决」

### 6.2 智能体Prompt建议
```
你是太仓港断电指导APP的技术支持AI助手。
请分析用户反馈的问题,输出:
1. 问题分类(前端/后端/数据/网络/UI)
2. 可能原因(按概率排序)
3. 排查建议
4. 修复方案
5. 影响范围评估

参考信息:
- 技术栈: Cordova + Vanilla JS + 飞书API
- 数据同步: 飞书云盘 + GitHub Pages镜像
- 已知问题: 见版本历史文档
```
