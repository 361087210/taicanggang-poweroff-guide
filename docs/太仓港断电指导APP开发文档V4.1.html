1. 项目概述

1.1 项目背景

太仓港作为国内重要商品车滚装港口，每日处理大量商品车的断电操作。为规范操作流程、提升作业效率，开发本应用，为现场作业人员提供断电位置查询、操作步骤指导、照片与视频参考、文档导出与云端同步等一站式服务。

V4.1 新增：应用内检查更新

  • 触发方式：启动 3 秒后静默自动检查；「我的 → 检查更新」手动触发（手动检查不受"跳过版本"限制）
  • 多源检测：GitHub Raw → jsDelivr CDN → 飞书云盘 version.json 兜底，单一源不可达自动降级
  • 更新展示：弹窗显示新版本号、发布日期、更新日志列表、安装包大小
  • 用户自主：可选「下载新版本安装包」（跳转 GitHub Release）或「稍后再说」（记住跳过版本）
  • 发版流程：更新仓库根目录 version.json + GitHub Releases 上传 APK 即完成发版
  • Word：基于 html-docx-js 生成 .docx，包含车辆图片（base64 嵌入）与视频链接信息
  • PDF：基于 jsPDF 生成 .pdf，含断电位置、操作步骤与图片信息
  • Excel：基于 xlsx.js 生成 .xlsx，含 photoPaths / videoPaths 字段
  • 分享：shareFile() 优先 navigator.share({files:...})，不支持时创建 <a download> 触发下载
// 文档分享：原生优先，下载兜底 function shareFile(blob,filename,mimeType){ if(navigator.canShare&&navigator.canShare({files:[new File([blob],filename,{type:mimeType})]})){ navigator.share({files:[...],title:filename}); // 原生分享面板 }else{ const a=document.createElement('a'); a.href=URL.createObjectURL(blob); a.download=filename; a.click(); // 回退下载 } }

4.1 车辆详情文档导出

详情页提供三个导出按钮，分别调用 exportSingle('word')、exportSingle('pdf')、exportSingle('excel')，生成后统一经 shareFile() 分享或下载。Word/Excel 均包含车辆图片（base64 嵌入）与视频链接信息。

4.2 车辆编辑媒体上传

编辑页将原占位按钮替换为真实 <input type="file">：拍照使用 capture="environment"，相册多选用 multiple，照片经 Canvas 压缩后以 base64 存入 photoPaths，视频校验大小后存入 videoPaths。编辑时 loadEditMedia() 自动渲染已有媒体预览，支持单张/单个删除。

4.3 数据中心备份与批量导出

数据中心提供备份目标单选（本地 / 飞书），doBackup() 根据选择下载 JSON 或上传飞书云盘；同时支持批量导出全部车辆为 Word/PDF/Excel（exportData()）。
