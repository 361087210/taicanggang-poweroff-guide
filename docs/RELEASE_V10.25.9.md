# V10.25.9 发布说明（资源库排版修复版）

- **发布日期**：2026-11-23
- **版本号**：10.25.9（versionCode 102509）
- **一句话总结**：截图复核时发现资源库的筛选条被压成 4px 边线（用户根本点不到），本版修掉排版，并把列表标题改成文件名。

## 问题（截图复核发现，非用户上报）

用无头 Chrome 逐屏截图时看到：资源库的筛选条只剩一条细线，「缺失/共享/云端视频…」一个也点不到。

**根因**：`css/app.css` 里

```css
.screen{position:absolute;inset:0;display:none;flex-direction:column;overflow:hidden;}
```

屏幕本身就是 **flex 列容器**，内容区直接作为它的子项时默认 `flex-shrink:1`；带 `overflow-x:auto` 的筛选行没有内在高度下限，被压缩到 **4px**（内容高 30px，实测 `rowH:4 btnH:12`）。

顺带发现：照片行标题用「车型名」、下一行又写一遍同样的车型名，读起来重复。

## 修复

| 项 | 内容 |
|---|---|
| 布局 | 头部固定 + 正文改放进 `.flex-1 .scroll-y .min-h-0`（与车型/同步等其他屏幕一致），筛选条恢复完整高度，滚动与底部安全区正常 |
| 标题 | 列表标题改为**文件名**（`北汽-极狐ARCFOX-T1_p1_ad644948.jpeg`），车型名只在下行显示 |
