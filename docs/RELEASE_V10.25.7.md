# V10.25.7 发布说明（资源库版）

- **发布日期**：2026-11-23
- **版本号**：10.25.7（versionCode 102507）
- **一句话总结**：照片和视频不再散落在四个目录、靠跑脚本才知道缺什么——App 里有了一页台账。

## 为什么做这一版

排查同类项目（离线优先的检修/点检类 PWA，如 [pmcs-pro](https://github.com/WCEdmonds/pmcs-pro)、Cordova 离线模板 [ionic3-angular4-cordova-sqlite-example](https://github.com/didinj/ionic3-angular4-cordova-sqlite-example)、以及飞书官方工具 [larksuite/cli](https://github.com/larksuite/cli)）后，我们最明显的差距不是"能不能离线"，而是**运维可见性**：

| 维度 | 参照项目做法 | 我们此前 | 本版 |
|---|---|---|---|
| 资产台账 | 统一 asset 索引 + 缩略图 | 只有 `audit:media` 的 stdout | ✅ 页面化台账 |
| 缺失可见 | 列表标注 + 一键导出 | 需要人跑脚本读日志 | ✅ 缺失筛 + 复制清单 |
| 共享/复用 | 显式 shared 标记 | 只能从路径 `_共享/` 猜 | ✅ 共享筛选 + 车型列表 |
| 孤儿文件 | 巡检报告 | 巡检报告 | ✅ 未归类/孤儿筛选 |
| 指纹 | 展示 hash | 0/64 有指纹，不可见 | ✅ 逐条显示"已指纹/未记录" |

## 本版做了什么

### 🟢 资源库（我的 → 资源库 / 侧滑菜单）
- **五档计数**：资产 314 / 照片 265 / 视频 49 / 缺失 63 / 共享 14
- **筛选**：缺失 · 共享 · 云端视频 · 未归类/孤儿 · 照片 · 视频
- **搜索**：车型名或文件名，实时过滤（只重画列表，不打断输入）
- **预览**：照片大图、云端视频说明、缺图提示；显示车型、路径、大小、指纹状态；可复制路径、跳转车型详情
- **复制缺失清单**：一键导出 `车型\t类型\t文件`，直接发给补拍/补传的人

### 🛠 索引生成器
`scripts/gen_media_library.js` → `docs/media_library.json`（114KB，随仓库发布，离线可用）：

- 路径规则**复用 `js/00-media-paths.js` 单一真源**，不在生成器里重写
- 状态：`ok` 正常 / `shared` 命中 `_共享/` / `unfiled` 命中 `_未归类/` / `remote` 视频在 Release / `missing` 全树缺失 / `orphan` 无引用的孤儿
- 同一文件被多台车引用时**去重成一条**并列出车型（"比亚迪海豚 … 等 2 台"）
- `--check` 模式：索引与仓库不一致即 `exit 1`，可接 CI 漂移门禁

### 🧪 测试
`tests/test_v10257_media_library.js`（39 断言）：纯函数（筛选/统计/清单）、索引契约（stats 与实算一致、无 U+FFFD、缺失数 63 与 `audit:media` 口径一致）、接线（屏幕/脚本/双入口/返回键/预缓存）、生成器幂等。

## 怎么用

1. 打开 App → 我的 → **资源库**
2. 想看还差什么素材：点「缺失」→ 点右上「复制缺失清单」→ 发给负责补拍的人
3. 想看某台车的图对不对：搜索车型名 → 点缩略图预览 → 「打开车型」看详情
4. 数据更新后：跑 `npm run media:library` 重新生成索引（或等 CI）
