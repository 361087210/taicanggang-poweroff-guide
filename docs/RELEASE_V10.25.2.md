## 本次解决的问题

### 品牌筛选"裂成两个选项"

**现象**：在 App 里按品牌筛选，"北汽"出现两次，各只有 1 辆车，用户以为数据丢了。

**根因**：两个车型的 `brand` 字段写法不同：

| 车型 | brand（修正前） | display |
|---|---|---|
| id 92 | `北汽BAIC` | 北汽BAIC-BJ30e |
| id 100 | `北汽(BAIC)` | 北汽-极狐ARCFOX-T1/T5 |

筛选器按字符串分组，于是同一品牌被拆成两组。

**修复**：统一为 `北汽(BAIC)`，品牌数 **12 → 11**。

> **刻意没有改 `display`**：`display` 同时是照片子目录名（`folderNameForVehicle`），
> 改动会切断该车型的全部媒体路径。本次只收敛筛选维度，媒体布局零变更。

### 其他字段是否有同类问题？

对 `brand / series / config / powerType / position` 五个字段做了归一化比对
（去括号、空格、连字符、全半角后再比较）：

| 字段 | 取值数 | 近似重复 |
|---|---|---|
| 品牌 | 11 | 已修复（原 12） |
| 车系 | 53 | 无 |
| 配置 | 68 | 无 |
| 动力类型 | 5 | 无 |
| 断电位置 | 23 | 无 |
