## 4. 架构重写方案

### 4.1 已确认决策
- **原生壳**：Capacitor 6（Cordova 官方继任者）+ Vite 5 + TypeScript 5
- **导出功能**：保留（含照片嵌入 Excel 等现有能力一并保留，不得简化掉）
- **数据与通知**：维持飞书 Bitable + Drive + 审批 + 群机器人
- **网页层**：GitHub Pages + 静态 `web-data` 镜像

### 4.2 ⚠️ 重写的核心难点（必须正视）
现有 `js/*.js` 各模块**通过隐式全局变量互相引用**（如 `00-bootstrap.js` 的 `const APP_VERSION`、`01-state.js` 的 `const State`、`12-bitable.js` 的 `window.FeedbackBase` 等并非 ESM `export`）。

这意味着：**不能简单地把 Vite 套上去**。Vite/Rollup 会把每个文件包进模块作用域，切断跨文件的隐式共享，直接导致运行时"xxx is not defined"。

正确做法是**逐模块改写为显式 ESM**（先小后大）：
```
推荐顺序: 小而独立模块 → feishu 单例 → 04-export(68KB) → 10-feedback/11-about
        → 03-vehicles(73KB) → 06-media(48KB) → 00-bootstrap(69KB) → 05-sync(97KB)
```
每个模块改写后立刻跑回归测试，禁止一次性批量替换。
