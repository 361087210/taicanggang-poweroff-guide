2. 签名事故发现与修复（本次交付最重要修复）

事故：Cordova CI 在 --buildConfig=build.json 模式下只认 build.json 内的签名字段，此前 workflow 仅写 release-signing.properties 被静默忽略，构建日志告警 'keystore' and 'alias' need to be specified —— V5.3.2-b3 与 V5.3.3-b4 两个 Release 产物实际未签名，真机安装必失败（"应用未安装"）。此缺陷在本轮交付终验的 APK 结构核验中被发现（ZIP 中无 APK Signing Block）。

修复措施（commit 7aff707）

  • 签名注入修复：签名四要素（keystore/storePassword/alias/password/keystoreType）经环境变量写入 build.json，密码零明文落仓库
  • 新增发布关卡：「校验APK签名」步骤检测 APK Signing Block v2/v3 魔数必须紧邻 Central Directory，未签名直接构建失败，从结构上杜绝坏包再发布
  • 坏包清除：GitHub 端删除 v5.3.3-b4 资产与 v5.3.2-b3 资产（v5.3.2 Release 已挂警示说明）；飞书端清理未签名旧 APK
  • 重建发布：v5.3.3 tag 重打到修复 commit，CI run#5 产出 b5 签名包并重新发布 Release
