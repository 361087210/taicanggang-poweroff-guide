# V10.6.0 真机冒烟验证方案

> 适用版本: V10.6.0 | 执行时机: 每次发版(CI出包)后、灰度/全量推送前
> 执行设备要求: Android 10 真机 ×1、Android 11+ 真机 ×1(各含组长端+组员端账号)
> 单项判定标准: 全部通过项=通过; 任一关键项(★)失败=阻断发版,回滚修复

## 二、S1-S3 文档导出重点核对清单

1. 文件后缀与真实格式一致: `.docx` 必须能被 WPS/MS Word 直接打开(非改后缀的HTML伪装件); `.pdf` 用系统PDF阅读器打开。
2. 中文核对: 车型名称、断电指导步骤、注意事项等中文字段逐屏检查,不得出现 □ 方块、问号、空白。
3. 照片核对: 内置车型照片与组长新增照片均需渲染(新增照片走 `vehicle_images/` 云端路径)。
4. 分享通道: 微信(文件助手+好友会话各一次)、QQ 至少抽验一个。

## 三、S4-S6 本地存储重点核对清单

1. 本地备份全程不得出现系统分享面板/应用选择器。
2. Android 10 与 Android 11+ 各验证一次「保存到下载」:
   - Android 10: 首次保存触发存储权限申请,授权后写入 `Download/太仓港断电指导`。
   - Android 11+: 不弹权限,直接写入成功。
3. 保存 ≠ 清理: 保存完成后缓存项仍在缓存列表中。

## 四、S7-S8 数据闭环核对清单

1. 组长新增含照片车型→同步→飞书云盘「APP数据备份/同步数据」JSON 中该车型 `photoPaths` 为 `vehicle_images/xxx.jpeg` 相对路径(非 base64)。
2. 「APP数据备份/vehicle_images」目录下出现对应照片文件。
3. 组员端同步后: 车型可见、照片可点开、杀进程重启数据仍在(IndexedDB持久化生效)。
4. 云端「注册申请」目录中跨网络申请文件被即消费即删,不累积。

## 五、失败处置

- 关键项失败: 立即停止推送,记录设备型号/Android版本/复现步骤,回滚至上一版本APK,建issue跟踪。
- 回归项失败: 不阻断发版,记录至 `docs/ITERATION_PLAN.md` 下一版本跟进。
- 全部通过后,在本文件末尾追加执行记录(日期/设备/执行人/结果)。
