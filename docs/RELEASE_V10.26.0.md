# V10.26.0 发布说明 — 资源库: 云端实测对账 + 组长上传/删除

## 一句话
在 V10.25.7/V10.25.8 台账的基础上，把资源库从「离线只读快照」升级为「可与飞书云端实际文件对账、并直接增删」的管理页，同时修掉 App 内「资源索引加载失败」。

## 背景
V10.25.7 的资源库解决了「看得见台账」，但仍有三处管理缺口：
1. 台账由 `media_library.json` 生成，天然滞后——云端新传/已删的文件在页面上看不出来；
2. 云端存在但没有任何车型引用的「孤儿文件」无法在 App 内发现和清理；
3. 组长补拍/删除素材仍要离开 App 去飞书网页操作，容易漏回写车型引用。

## 本版改动

### 1. 核对云端（新增）
- 顶部「核对云端」按钮：扫描 `APP数据备份/vehicle_images`、`vehicle_videos` 的实际文件（含车型子目录与旧布局下的顶层散落文件）。
- 每条台账行新增云端状态徽标：`云端✓`（存在）/ `云端✗`（不存在）。
- 顶部信息行展示：云端照片数 · 视频数 · 无台账文件数 · 核对时间。
- 核对结果只保存在内存，不修改 `media_library.json`（索引仍由 `scripts/gen_media_library.js` 维护）。

### 2. 云端孤儿（新增）
- 云端存在但台账无引用的文件直接并入「未归类/孤儿」筛选，可预览、可删除。
- 路径保持 `vehicle_images|videos/<车型目录>/<文件名>` 三段式，便于人工定位。

### 3. 组长上传（新增）
- 页头「上传」（仅组长可见）→ 选择车型 → 批量选择照片/视频。
- 自动创建顶层目录与 `<车型目录>`；文件名 `<车型>_p<序号>_<hash>.<ext>` / `<车型>_v<序号>_<hash>.<ext>`。
- 上传成功后回写 `photoPaths` / `videoPaths`（经 `State.updateVehicle`），并即时出现在台账列表。

### 4. 组长删除（新增）
- 预览弹层内「删除云端文件（并解除引用）」：二次确认后调用 `driveDeleteFile`，并剥离所有车型中的同名引用。
- 不可恢复，按钮使用红色弱提示样式。

### 5. 云端预览（新增）
- 台账标记缺失/孤儿、但云端实测存在时，预览中提供「云端加载」，通过门控下载 `feishuDownloadFile` 直接读取图片/视频。

### 6. 索引加载修复（App）
- 根因一：Android/iOS 打包脚本没把 `media_library.json` 拷进 `www/`，App 内相对路径请求必然 404。
- 根因二：`fetch()` 在 `file://`（iOS `app://`）协议下不可用，Cordova 壳里直接报「资源索引加载失败」。
- 修复：打包脚本补拷索引并加存在性校验；前端加载改为 `fetch → XHR → 线上 Pages 索引` 三级兜底，错误信息保留可定位原因。
- 索引随包发布，App 离线也能打开资源库；线上兜底仅用于索引缺失/本地读取失败的场景（需联网一次）。

## 兼容与降级
- 未登录、无飞书配置或离线时：台账照常只读可用，核对/上传/删除给出明确提示，不崩溃。
- 保留 V10.25.7 全部能力：五档计数、筛选、搜索、预览、复制路径、跳转车型、缺失清单一键复制。

## 工程
- 版本七源同步 `10.26.0`（versionCode `102600`）：`config.xml` / `version.json` / `release/version.json` / `js/00-bootstrap.js` / `js/11-about.js` / `sw.js` / `demo.html`。
- 缓存名升级 `tcg-poweroff-v10.26.0`，避免旧壳缓存导致新模块不生效。
- `tests/test_v10257_media_library.js`（59 断言）保持通过：纯函数、索引契约、云端对账、上传删除、索引加载兜底（fetch→XHR→线上）与打包校验。

## 升级注意
- `versionCode` 已变更，需重新构建 APK 才会带出本版；网页端刷新即可。
- 上传/删除依赖飞书应用具备 `drive:drive` 写权限与目标文件夹的编辑权限。
