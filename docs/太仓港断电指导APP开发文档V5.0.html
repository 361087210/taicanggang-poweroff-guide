1. 项目概述

1.1 项目背景

太仓港作为国内重要商品车滚装港口，每日处理大量商品车的断电操作。为规范操作流程、提升作业效率，开发本应用，为现场作业人员提供断电位置查询、操作步骤指导、照片与视频参考、文档导出与云端同步等一站式服务。

2. 版本更新日志

2.1 V5.0 修复明细

问题根因修复方案影响
车辆详情页视频不显示 demo.html 内嵌 VEHICLES 数组缺少 videoPaths 字段，视频路径仅存在于 vehicles_data.js 外部文件中，详情页无法读取 编写 merge_videos.cjs 脚本，将 vehicles_data.js 中的 videoPaths 合并到 demo.html 内嵌数组 致命 视频无法播放 → 43 款车型视频正常播放

2.3 V5.0 代码变更要点

2.3.1 视频路径合并（merge_videos.cjs）

通过 Node.js 脚本将 vehicles_data.js 中的 videoPaths 按 id 匹配合并到 demo.html 内嵌 VEHICLES 数组，详情页可直接读取视频路径并渲染播放器。

// merge_videos.cjs 核心逻辑 const vdata = fs.readFileSync('vehicles_data.js', 'utf8'); // 提取 videoPaths 映射: id -> { videoPaths, videos } for (const v of sandbox.VEHICLES) { if (v.videoPaths && v.videoPaths.length > 0) { videoMap[v.id] = { videoPaths: v.videoPaths, videos: v.videoPaths.length }; } } // 按 id 匹配 demo.html 中的车辆行，注入 videoPaths 字段 html = html.replace(/videos:\d+/, 'videos:' + info.videos + ',videoPaths:' + JSON.stringify(info.videoPaths)); // 结果：43 款车型获得视频播放能力

2.3.2 编辑页媒体加载修复（loadEditMedia）

移除 p.startsWith('data:') 过滤，使所有媒体路径（含相对路径）均被加载到编辑预览区。

// 修复前：过滤非 base64 路径（BUG） // editPhotos = v.photoPaths.filter(p=>p.startsWith('data:')).map(...) // 修复后：加载全部路径 function loadEditMedia(v){ editPhotos = []; editVideos = []; if (v && v.photoPaths) { editPhotos = v.photoPaths.map(p => ({ name: 'existing', data: p })); } if (v && v.videoPaths) { editVideos = v.videoPaths.map(p => ({ name: 'existing', data: p, size: 0 })); } renderPhotoPreview(); renderVideoPreview(); }

2.3.3 导出库加载检查

在 exportData() 与 exportSingle() 中增加库可用性检查，加载失败时给出明确提示而非静默报错。

// exportData / exportSingle 前置检查 if ((format === 'excel' && !window.XLSX) || (format === 'pdf' && !window.jspdf) || (format === 'word' && !window.htmlDocx)) { showToast(names[format] + '库加载失败，请检查网络后重试'); return; }

2.3.4 飞书备份配置读取修复（doBackup）

doBackup 改为从 localStorage 读取用户保存的飞书配置，回退到默认配置；FormData 正确附加 file 字段。

// doBackup 读取用户配置（回退默认） const saved = JSON.parse(localStorage.getItem('feishu_config') || '{}'); const cfg = { appId: saved.appId || DEFAULT_FEISHU_CONFIG.appId, appSecret: saved.appSecret || DEFAULT_FEISHU_CONFIG.appSecret, folder: saved.folder || DEFAULT_FEISHU_CONFIG.folder, interval: saved.interval || DEFAULT_FEISHU_CONFIG.interval }; // FormData 补全 file 字段 const formData = new FormData(); formData.append('file_name', filename); formData.append('parent_type', 'explorer'); formData.append('parent_node', cfg.folder); formData.append('size', String(blob.size)); formData.append('file', blob, filename); // 关键：附加文件内容

2.3.5 备份历史记录

每次备份成功后自动记录，保留最近 10 条，在数据中心页面渲染展示。

// 记录备份历史 function addBackupHistory(type, filename, count, size) { let history = JSON.parse(localStorage.getItem('backup_history') || '[]'); history.unshift({ type, filename, count, size, time: new Date().toLocaleString('zh-CN') }); history = history.slice(0, 10); // 保留最近 10 条 localStorage.setItem('backup_history', JSON.stringify(history)); renderBackupHistory(); } // 渲染备份历史（本地/飞书云标签 + 条数 + 大小 + 时间） function renderBackupHistory() { const c = document.getElementById('backup-history'); if (!c) return; let history = JSON.parse(localStorage.getItem('backup_history') || '[]'); // 按类型显示标签（本地/飞书云）、数据条数、文件大小、时间 c.innerHTML = history.map(h => '...').join(''); }

async function exportSyncConfig() { const saved = JSON.parse(localStorage.getItem('feishu_config') || '{}'); const cfg = { appId: saved.appId || DEFAULT_FEISHU_CONFIG.appId, ... }; const exportData = { type: 'sync_config_backup', version: 'v' + APP_VERSION, timestamp: new Date().toISOString(), feishuConfig: { appId: cfg.appId, folder: cfg.folder, interval: cfg.interval }, vehicleCount: VEHICLES.length, vehicles: VEHICLES.map(v => ({ id, brand, series, config, display, powerType, position, steps, keyFrame, keyContainer, remarks, photos, photoPaths, videos, videoPaths })) }; const blob = new Blob([JSON.stringify(exportData, null, 2)], { type: 'application/json' }); await shareFile(blob, 'sync_config_' + date + '.json', 'application/json'); }

3. 技术架构

3.1 整体架构

本应用为 HTML5 单页应用（SPA），通过 Cordova 封装为 Android 原生应用。所有界面在一个 demo.html 中通过 showScreen() 切换，无需路由框架，离线可用。车辆数据内嵌于 demo.html 的 VEHICLES 数组，V5.0 起视频路径已合并至内嵌数组，无需外部数据文件即可播放视频。

3.2 技术栈

层级技术 / 库用途
UI 框架HTML5 + Tailwind CSS（CDN）响应式布局与组件样式

文档生成jsPDF 2.5.1 + autotable 3.5.31导出 PDF（.pdf），含照片与视频路径信息

4.1 车辆详情与视频播放

详情页展示断电位置、操作步骤、钥匙处理方式、照片参考与视频播放。V5.0 修复后，43 款车型的 videoPaths 已合并到内嵌 VEHICLES 数组，详情页可直接渲染 <video> 元素播放视频。详情页提供三个导出按钮，分别调用 exportSingle('word')、exportSingle('pdf')、exportSingle('excel')，导出前检查库加载状态。

4.2 车辆编辑媒体上传

编辑页将原占位按钮替换为真实 <input type="file">：拍照使用 capture="environment"，相册多选用 multiple，照片经 Canvas 压缩后以 base64 存入 photoPaths，视频校验大小后存入 videoPaths。V5.0 修复后，loadEditMedia() 移除 data: 前缀过滤，编辑时自动渲染已有内置媒体预览（照片与视频），支持单张/单个删除。

4.3 数据中心：备份、历史与批量导出

数据中心提供备份目标单选（本地 / 飞书），doBackup() 根据选择下载 JSON 或上传飞书云盘（V5.0 修复后读取用户保存配置并正确附加 file 字段）；备份成功后 addBackupHistory() 自动记录，renderBackupHistory() 在页面渲染最近 10 条备份记录（含类型标签、条数、大小、时间）。同时支持批量导出全部车辆为 Word/PDF/Excel（exportData()），导出前检查库加载状态。

4.4 同步中心：云端同步与配置导出

同步中心提供飞书云端上传（doSyncUpload）与下载（doSyncDownload），自动加载用户保存的飞书配置（回退默认）。V5.0 新增 exportSyncConfig() 配置导出功能，将车辆数据与飞书配置导出为 JSON 文件，便于环境迁移与数据归档。
