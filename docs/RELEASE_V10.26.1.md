# V10.26.1 发布说明（首屏提速版）

- **发布日期**：2026-11-23
- **版本号**：10.26.1（versionCode 102601）
- **一句话总结**：只查一台车也要先下 1.8MB 导出套件的日子结束了——模拟 4G 下 FCP **6.9s → 3.6s**。

> 说明：`10.26.0` 是资源库云端对账版（另一条线已发布）。本版在其基础上做**性能优化**，不重复那批功能。

## 为什么做这一版

体检发现：`demo.html` 的 `<head>` 里 6 个 vendor 脚本**全都没有 defer**，其中 5 个（xlsx / jsPDF / autotable / html-docx / html2canvas，合计约 **1.8MB**）**只被导出链路使用**。用户打开 App 只为看一眼某台车怎么断电，却要先阻塞下载整个导出套件。

同一轮体检的另外两个体积问题：12 张 PNG 占 4.96MB（照片存成了无损 PNG）、`docs/参考资料` 4 份手册占 **57MB**（仓库体积的 96%）。

## 改了什么

### ⚡ 1. 导出组件按需加载

- `demo.html`：移除 5 个导出库的 `<script>`；`tailwind.js`（样式必需）与 `cordova.js`（Cordova 桥）保留
- `js/04-export.js`：新增 `ensureExportLibs()`
  - 幂等：按 `src` 记忆 Promise，多入口同时点也只下载一次
  - 不阻塞：`s.async = true`
  - 不改变降级：加载失败仍走原有「库加载失败 → 降级方案」提示
- `exportData()` / `exportSingle()`：在**库判空之前** `await ensureExportLibs()`（顺序很关键，否则会误报"库加载失败"）
- `sw.js` **仍预缓存** 5 个库 → 离线导出能力不退化（首次导出会提示「正在加载导出组件…」）

### ⚡ 2. 图片重编码

12 张 PNG 用调色板 PNG（256 色 + dither）重编码，**保持原路径与原扩展名**，因此数据（`photoPaths` / 映射表 / manifest / 云盘）**零改动**：4.96 MB → **1.89 MB**（省 3.07MB）。
单张示例：`_共享/image158.png` 758KB → 298KB，`长城好猫/image63.png` 708KB → 237KB（已人工目检）。

### 🧹 3. 参考资料出仓

`docs/参考资料`（4 份手册/截图，57MB）→ 归档 Release **`refdocs-2026-11`**（tag 故意不用 `v*` 前缀，避免触发发版流水线）：

| 归档文件 | 原文件 | 体积 |
|---|---|---|
| `pdf-tangL-poweroff.pdf` | 比亚迪唐L断电操作.pdf | 9.5 MB |
| `pdf-app-screenshots.pdf` | 断电指导软件截图(1).pdf | 20.2 MB |
| `docx-manual-20260603.docx` | 太仓港商品车断电操作手册20260603版.docx | 20.6 MB |
| `docx-manual.docx` | 太仓港商品车断电操作手册.docx | 6.0 MB |

工作树 **75MB → 18MB**。新增 `docs/参考资料.md` 记录归档位置，`.gitignore` 防回流。

> `.git` 仍保留历史（约 58MB）。彻底瘦身需 `git filter-repo` 重写历史，属高风险操作，另行评估。

### 🔧 4. 适配 10.26.0 的发版校验

`android-release.yml` 原有校验是「`demo.html` 里必须能 grep 到 `vendor/html-docx.js`」——本版把该引用移走后它会**硬拦截发版**。已改为两条更有意义的断言：

1. `js/04-export.js` 的装载清单必须含 5 个 vendor 路径（否则导出静默失效）
2. `demo.html` **不得**再把导出库写回首屏（要求是"库打进包 + 按需加载"，不是"必须在 head"）

同时订正 `tests/test_v106_fixes.js` A1（原断言同样绑死在 head 标签这一实现细节上）。

## 实测对比（无头 Chrome，430×932 2x DPR，模拟 4G 200KB/s + 150ms RTT）

| 指标 | 优化前 | 本版 |
|---|---|---|
| FCP 首次内容渲染 | 6.92 s | **3.57 s**（-48%） |
| 首屏 `<script>` 数 | 28 | **23** |
| 首屏是否下载导出库 | 是（1.8MB 阻塞） | **否**（首次导出才下载） |
| 12 张 PNG | 4.96 MB | 1.89 MB |
| 工作树体积 | 75 MB | 18 MB |

导出功能实测有效：按需加载后 `XLSX/jsPDF/autotable/htmlDocx/html2canvas` 全部就绪，`generateExcelBatch()` 成功产出 20,984 字节 xlsx。

## 已知与遗留

1. 首次导出需多等一次组件下载（已提示；之后走浏览器缓存与 SW 预缓存）
2. Tailwind 仍是运行时版本（441KB）——预编译成静态 CSS 可再省约 400KB，属下一步
3. `audit:media` 报 **31 条「声明未上传」**：云端数据把照片声明在车型目录下、实际文件在 `_共享/`，靠客户端候选回退显示正常；需业务侧决定「复制到车型目录」还是「改回 `_共享` 引用」
4. 视频指纹仍 0/64
