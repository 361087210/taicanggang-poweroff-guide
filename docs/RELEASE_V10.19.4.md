# V10.19.4 环境对齐与别名安全加固版 — 发布说明

> 版本号：10.19.4 ｜ versionCode：101904

## 一句话

飞书配置全面对齐新应用/新文件夹/新问题反馈库，并给视频别名解析补上「归一化键歧义整体拒绝」的安全边界，同时修复注册投递版本号残留、视频映射同步语法隐患，并彻底清除车辆数据中的编码替换符残留。

## 本次内容

### 配置（对齐）

- 飞书 `appId` / `folderToken` / `bitableAppToken` / `bitableFeedbackTableId` 更新为新环境实值（新应用 `cli_aa315800e5f8dd14`、文件夹 `CeT0fYNgalU4fQdW9etcJLJGn1b`、问题反馈库 `Rv29b7CMAaKXj3sH2RBcRS5rnWb`）。
- 修复 Python 发版脚本读取 `folderToken` 字段（不再回退到旧默认值）。

### 安全（视频别名）

- 别名解析对「归一化键歧义」**整体拒绝**——同一归一化键有 ≥2 份源资产，或查询键为其它资产键前缀时，一律不猜（宁可漏不可错），杜绝断电教学视频看错车型。
- 长安深蓝(G318) / 长安启源(EADO PLUS) 的 v2 重传属已知歧义，靠精确名直链播放。

### 修复（编码与数据完整性）

- **修复（编码）**：清除 `vehicles_data.js` 中全部 14 处 U+FFFD 替换符残留（钥匙盒/断电步骤等 7 处文案），并扩充生成器校正表 9 条（产物侧 6 处 + 镜像侧 3 处新损坏），保证下次飞书同步不回归。
- **修复（映射）**：清理 `MEDIA_DIRECT_ASSETS` 中 3 个无引用孤儿键（`user_v` 旧命名，已迁移至新资产名），映射表与车辆数据 49 项引用完全对齐。

### 修复（功能）

- **修复（注册投递）**：`js/09-web-sync.js` 残留 `window.APP_VERSION`（顶层 const 不挂 window，恒取 undefined）改为 `APP_VERSION`，注册审批投递的 `appVersion` 字段不再丢失。
- **修复（同步脚本）**：`sync_videos_to_release.js` 插入新映射行时若原最后一项无尾逗号先补逗号，避免对象字面量语法断裂。

### 工程

- 视频播放专项测试新增「歧义拒绝 / 前缀歧义」断言，全量 47 套件通过（飞书跨网络套件缺凭据时跳过）。
- 通知群迁移至新租户群（旧群跨租户不可达），代码配置/版本文件/测试断言同步更新。
