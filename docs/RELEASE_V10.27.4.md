# V10.27.4 — 车型详情 ↔ 资源库双向联动（正式发布）

## 一句话
车型详情页的每张照片/视频现在都能看出它在资源库里的状态，点一下就能跳到资源库对应位置；资源库也能反过来只看某台车的素材。

## 用户可见变化
- **详情页状态徽标**：照片格子 / 视频卡片右上角显示 `正常 / 共享 / 云端 / 缺失 / 低清`，低清会与状态并列（如 `共享 · 低清`）；缺失项红底标注，不用再靠“图裂了”才发现。
- **板块汇总**：「车辆照片」「视频演示」标题旁显示 `N 项 · N 缺失 · N 共享 · N 低清`，照片与视频分别统计。
- **点按定位**：点徽标 → 打开资源库并自动翻到该资产所在分页，高亮对应行。
- **只看这台车**：板块标题右侧「资源库 ›」→ 资源库只显示该车型引用的资产，顶部可一键清除收窄；资源库原有的「打开车型」保持，形成双向闭环。

## 工程说明
- 状态来自 `media_library.json`（构建期索引）+ 运行时车型引用合并；新增/删除的引用按 `待入库` / 自动消失处理。
- 索引加载做了去重：详情页装饰与资源库台账共用一次请求；索引不可用时静默降级，详情页照常可用。
- 收窄后的分页与总数统一走 `filteredAssets()`，避免「只看这台车」时页码与实际列表不一致。

## 发版修复
- 补齐本文件 `docs/RELEASE_V10.27.4.md`。10.27.3 的 tag 已存在，但 Android/iOS Release 流程要求 `body_path: docs/RELEASE_V<版本>.md`，缺失导致构建在创建 Release 前失败，因此未实际发布；本版补齐后重新发版，功能与 10.27.3 一致。
