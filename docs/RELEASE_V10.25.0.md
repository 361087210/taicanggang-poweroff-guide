# V10.25.0 媒体工程化版 — 发布说明

> 版本号：10.25.0 ｜ versionCode：102500 ｜ 发布时间：2026-10-10

## 一句话

把图片与视频从「靠文件名约定」改为**按车型名分文件夹存储**（GitHub 与飞书两侧同构），以单一真源加运行时三段式路径下钻定位，从目录结构上杜绝媒体与车型错配；同步补上账号注销防复活（墓碑机制）、自助注销与账号生命周期三处安全加固，并新增代码库知识文档、web-data 脱敏门禁与行覆盖率验收门禁。

## 背景：为什么会错配，为什么现在修

媒体与车型的对应关系此前只靠**文件名里的车型名**约定，目录是扁平的。一旦重名、改名、批量搬运或人工误传，文件就会挂到错误车型下，而且没有结构性防线能拦住。这类错配在断电作业现场是**安全事故级**的问题——操作员照着错的照片拔错部件。

同时，账号侧的三条删除路径各自为政，注销后仍可能被云端审批名单「复活」；忘记密码、登出、改密三处的会话处理也存在跨设备仲裁失效与残留串号的隐患。

## 本次内容

### 1. 媒体按车型名分文件夹（GitHub + 飞书同构）

- **单一真源** `js/00-media-paths.js` 统一生成三段式路径（柜体规格 / 车型名 / 部位）。路径只在一处生成，GitHub 与飞书两侧同构，避免两套规则各自漂移。
- **运行时三段式下钻定位**：`js/04-export.js`、`js/05-sync.js`、`js/06-media.js` 按 `04-export` / `05-sync` / `06-media` 三段逐级解析。**命名即归属**——文件落在哪个车型目录，就属于哪个车型。
- **存量迁移** `scripts/migrate_media_to_folders.js`：单车 **163** + 共享 **14** + 未归类 **16**，合计 **193** 个文件按新结构归位。

### 2. 账号生命周期加固

- **注销防复活（墓碑机制）**：新增独立存储键 `tcg_deleted_users`，三条删除路径统一经 `State.removeUser` 收口落墓碑；云端 `approved_users.json` 增 `deleted` 名单跨设备传播"已注销"事实；所有「云端 → 本地」复活点以 `isPhoneTombstoned` 前置拦截，重新注册时以 `clearTombstone` 作废旧标记。
- **自助注销**：新增 `cancelAccount` 自助注销入口（菜单 + `js/02-auth.js`），用户可自主发起注销，不再依赖人工后台。
- **忘记密码跨设备仲裁失效**：`doForgotPassword` 重置后补写 `pw_ts`，修复跨设备密码仲裁失效。
- **登出残留导致换号串号**：`doLogout` 清理会话与账号作用域缓存，避免换号后读到上一账号数据。
- **篡改会话绕过校验**：`changePassword` 改密后重建会话并重新签名 `sig`，修复被篡改会话绕过校验。

## 风险与边界

- **迁移是结构变更**：`_未归类/` 下 16 个文件为存量无法归属者，仍需人工确认归属后并入对应车型目录。
- **旁支待补**：飞书云端尚有 65 个缺失文件待补传；C3 有 2 条视频跨车共用，待补 `sha256` 以明确归属。
- 本版**不改变**断电操作语义与业务流程，媒体定位方式与账号生命周期为唯二的行为面变更。
