## 一、新增功能

### 组员端数据同步页 — 导入备份

**需求**: 组员端数据同步页缺少导入备份功能,组员无法从本地备份文件恢复数据。

**实现**:

在数据同步页「同步操作」区块新增「导入备份 — 从本地恢复」入口,位于「导出配置」下方、「设备间传输」上方。

```
同步操作
├── 上传数据至飞书 / 从飞书获取数据 (依角色切换)
├── 手动拉取飞书数据
├── 导出配置 — 备份本地
├── 导入备份 — 从本地恢复   ← V10.9.1 新增
└── 设备间传输
```

**功能流程**:

```
点击「导入备份」
    ↓
调起系统文件选择器 (accept=".json")
    ↓
选择 cloud_sync_config.json 备份文件
    ↓
FileReader 读取文本 → JSON.parse
    ↓
格式识别 (三种兼容格式)
    ↓
统计: 新增X条 / 覆盖Y条
    ↓
二次确认弹窗
    ↓ 确认
智能合并: 同ID覆盖 / 新增追加
    ↓
persistVehicles() 持久化
    ↓
刷新列表 + Toast提示 + 同步日志记录
```

**兼容格式**:

| 格式 | 识别条件 | 来源 |
|------|---------|------|
| 标准备份 | `data.type === 'sync_config_backup'` | exportSyncConfig 导出 |
| 旧版备份 | `data.type === 'vehicle_poweroff_backup'` | 历史版本导出 |
| 裸数组 | 顶层为数组且首项有 `id` 字段 | 手动导出/第三方 |

**权限设计**:

- 组长: 可导入 (本地恢复 + 之后可上传至飞书)
- 组员: 可导入 (本地恢复,不涉及上云)
- 理由: 导入是**本地数据恢复**操作,不涉及云端写入,因此组员端也开放

**安全防护**:

- 文件大小上限: 50MB
- 格式校验: JSON parse 失败即报错
- 二次确认: 显示新增/覆盖数量,用户确认后才执行
- 结果可追溯: 导入结果写入同步日志

## 三、向后兼容性

- **导出格式不变**: `exportSyncConfig()` 输出格式完全不变,两端互认
- **导入格式向前兼容**: 支持 V10.6.0 以来的所有备份格式
- **组员端角色权限**: `canEdit()` 不变,上传仍仅限组长;导入为本地操作,全员开放
- **数据结构**: 导入的车辆字段与现有 VEHICLES 结构完全对齐

## 四、使用场景

| 场景 | 操作路径 |
|------|---------|
| 新设备装机(组员) | 组长导出备份 → 微信/蓝牙发送 → 组员导入备份 → 即可使用 |
| 换机恢复(组员) | 从旧机导出备份 → 新机导入 → 数据恢复 |
| 离线环境 | 没有飞书网络时,通过本地备份在设备间传递数据 |
| 数据回滚 | 误操作后,从历史备份文件恢复到指定版本 |
